About This Project

This is a simple website created to help learn Node.js development. It demonstrates:

  • Setting up an Express server
  • Creating routes
  • Serving static files
  • Basic templating
  • Handling form submissions
  • Creating API endpoints

Technologies Used:

  • Node.js
  • Express.js
  • HTML/CSS
  • JavaScript (client-side)
